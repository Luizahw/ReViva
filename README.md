# ReViva ♻️

## Sobre o projeto

O ReViva é uma plataforma web que incentiva a reciclagem e o descarte correto de resíduos, promovendo hábitos sustentáveis e a preservação do meio ambiente.

## Problema

O descarte incorreto de resíduos e a falta de informação sobre reciclagem contribuem para a poluição ambiental. O ReViva busca facilitar o acesso a informações e incentivar a participação da população.

## Objetivo

Incentivar a reciclagem por meio de uma plataforma que informa, registra ações sustentáveis e recompensa os usuários com pontos.

## Funcionalidades previstas

- Cadastro e login de usuários;
- Consulta de materiais recicláveis;
- Consulta de pontos de coleta;
- Registro de reciclagens realizadas;
- Sistema de pontos por reciclagem;
- Histórico de atividades;
- Metas e desafios sustentáveis.

## Tecnologias

- **Frontend:** HTML, CSS e JavaScript;
- **Backend:** Node.js e Express;
- **Banco de dados:** MySQL;
- **Autenticação:** futuramente, com senhas protegidas e JWT.

## Público-alvo

Pessoas interessadas em reciclagem, sustentabilidade e descarte correto de resíduos, além de organizações e pontos de coleta.

## Estrutura do projeto

- `backend/`: lógica do sistema e API;
- `frontend/`: páginas e interface do usuário;
- `sql/`: arquivos relacionados ao banco de dados;
- `README.md`: documentação do projeto.

## Etapas de desenvolvimento
